Terraria (Re-Logic) is a 2D sandbox game on Microsoft's XNA Framework 4.0, the framework [MonoGame](/engines/monogame/) reimplements;
its install ships the XNA 4.0 redistributable. :observed{games="terraria"} The observations are of Steam app 105600, build
24893155. :observed{games="terraria"}

## Data in the install

`Content` holds the game's assets as 15,994 [XNB files](/engines/monogame/archives/xnb-containers/), every one of platform `w`
and version 5; 15,108 of them are [LZX-compressed](/engines/monogame/archives/xnb-containers/#compression). :proven{games="terraria"}
