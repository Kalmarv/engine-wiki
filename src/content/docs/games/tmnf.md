TrackMania Nations Forever (Nadeo, 2008) is a racing game built on Nadeo's [GameBox engine](/engines/gamebox/). Its tracks are
map files in the engine's GBX format. :sourced[GBX.NET]

The facts recorded for it come from map files downloaded from TrackMania Exchange, compared with the reference reader
GBX.NET, not from the game's install or executable. Some of those maps were made with TMUnlimiter, a community extension, and
carry data the stock game does not write. :observed
