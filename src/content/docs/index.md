This wiki is a reference for how game engines store, load and process their assets: archives, meshes, materials,
shaders, worlds, collision, animation and the runtime that consumes them. It is written for people and for programs
alike, and organised like an engine team's internal documentation: by engine and by system, with the differences
between games that share an engine written where they occur.

Every statement carries a confidence level, from **Proven** to **Unknown**. The [coverage page](/coverage/) adds them up:
what is known about each game, how surely, and what is still open.
